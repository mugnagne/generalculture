# Sons du jeu (facultatifs)

Déposez vos fichiers audio (`.ogg` ou `.mp3`) dans ce dossier, puis déclarez-les dans `sons.json` :

```json
{
  "clic": "clic.ogg",
  "bonne": "bonne.ogg",
  "mauvaise": "mauvaise.ogg",
  "coup": "coup.ogg",
  "victoire": "victoire.ogg",
  "defaite": "defaite.ogg",
  "conquete": "conquete.ogg",
  "musique-titre": "titre.mp3",
  "musique-carte": "carte.mp3",
  "musique-combat": "combat.mp3",
  "musique-boss": "boss.mp3",
  "musique-finale": "finale.mp3"
}
```

Toutes les clés sont facultatives : un son absent est simplement ignoré.
Pensez à créditer les auteurs dans `CREDITS.md`. Touche **M** en jeu : couper / rétablir le son.
